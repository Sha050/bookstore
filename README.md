# 📚 Bookstore API

A simple RESTful API built with Express.js and MongoDB to manage a collection of books.

## 🚀 Features
- Add new books
- Fetch all books
- Fetch a book by ID
- Update book details
- Delete a book

## 🧠 Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
